# Employee Management System

The **Employee Management System** project allows you to manage all employee information within a database. The system lets you add, update, view, and delete employee details as required. It helps track employee information like name, phone number, address, salary, email, etc., and facilitates easy management of this data.

## Features
- **Add Employee**: Add new employee details to the database.
- **View Employee**: View existing employee information.
- **Update Employee**: Modify employee details if there are any changes.
- **Remove Employee**: Delete employee records if the employee leaves the company.

## Technologies Used
- **Core Java** (Swing & AWT): Used for developing the GUI of the application.
- **Database**: MySQL for storing employee data.
- **IDE**: IntelliJ IDEA for development.



## Setup Instructions
1. **Clone or Download** the repository to your local machine.
2. **Install MySQL**: Make sure MySQL is installed on your machine. Create a database and table as per the `SQL` instructions.
3. **Configure Database**: Set up your database connection in the project using the `conn` class. Update the connection parameters (`username`, `password`, `database name`) as needed.
4. **Run the Application**: Open the project in IntelliJ IDEA, build it, and run the `Splash` to start the application.

## How to Use
1. **Add Employee**: Go to the "Add Employee" section and enter the required details. Once completed, click **Add** to save the data in the database.
2. **View Employee**: You can view all employees' details and search by their ID.
3. **Update Employee**: Select an employee and update the required details.
4. **Delete Employee**: Select the employee you want to delete and confirm the deletion.
